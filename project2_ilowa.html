AI Agent 기반 구인·구직 자동화 서비스 (Ilowa)

FastAPI PostgreSQL Docker Clova OCR/STT LLM React

Overview

AI 에이전트를 활용하여 시니어 맞춤형 일자리를 추천하고, 오프라인 공고를 OCR/STT로 자동화하여 플랫폼에 공급하는 서비스입니다. 공급자(구직자)와 수요자(시니어 구인자)를 연결하는 것을 목표로 설계했습니다.

My Role

  • 시니어 대상 간편 UI 설계
  • Naver Maps 실시간 공고 연동
  • Backend/DB/인프라 설계 및 Docker 기반 실행 환경 구축 보조
  • 최종 발표 준비 및 피칭

Key Implementation

  • Docker Compose 기반 db + api + ai 통합 실행 환경 구축
  • 외부 AI API를 서비스 레이어로 래핑하여 의존성 최소화
  • CSV + OCR 데이터 통합 및 PostgreSQL 적재
  • Geocoding을 통한 위치 데이터 자동 보정

Troubleshooting

  • WSL/맥 환경 차이로 Docker 실행 실패 → 경로/포트 문제 해결
  • 팀원 환경 불일치 → docker compose 기반 통일된 실행 환경 구축

Impact

AI 기능과 인프라를 결합한 실제 서비스 형태의 프로젝트를 수행하며, 서비스 아키텍처 설계와 DevOps 환경 구축 경험을 동시에 확보했습니다.
