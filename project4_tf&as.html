Terraform & Ansible Architecture

Terraform & Ansible 기반 인프라 자동화

Terraform Ansible AWS VPC IaC High Availability

Overview

Terraform을 활용해 AWS 인프라를 코드로 구축하고, Ansible을 통해 서버 초기 설정과 서비스 환경을 자동화한 프로젝트입니다. 네트워크 구조 설계부터 서버 구성까지 일관된 자동화 환경을 구축하는 것을 목표로 했습니다.

Architecture

  • VPC 기반 Public / Private Subnet 분리
  • Internet Gateway + NAT Gateway 구성
  • Private Subnet에 EC2 배치
  • Multi-AZ 기반 고가용성 확보

Network

  • VPC: 10.0.0.0/16
  • Public Subnet: 10.0.1.0/24, 10.0.2.0/24
  • Private Subnet: 10.0.11.0/24, 10.0.12.0/24

Routing

  • Public → Internet Gateway 연결
  • Private → NAT Gateway 통해 외부 통신
  • 외부 직접 접근 차단 구조

Automation Flow

  • Terraform으로 인프라 리소스 생성
  • Ansible로 서버 설정 및 서비스 구성 자동화
  • 인프라 + 애플리케이션 환경 통합 관리

Key Implementation

  • Infrastructure as Code 기반 인프라 자동화
  • Public/Private 네트워크 분리 설계
  • Terraform + Ansible 역할 분리
  • 고가용성 아키텍처 구성

Impact

수동 구축이 아닌 코드 기반 인프라 관리 경험을 통해 클라우드 환경에서의 운영 자동화와 확장성 있는 구조 설계 역량을 확보했습니다.
