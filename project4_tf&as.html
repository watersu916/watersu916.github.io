Terraform & Ansible 기반 인프라 자동화

Public/Private Subnet 기반 AWS 인프라를 코드로 구축하고 서버 구성까지 자동화한 프로젝트

Terraform Ansible AWS VPC IaC High Availability

📌 Overview

Terraform을 사용하여 AWS 네트워크 및 인프라를 자동으로 구축하고, Ansible을 통해 EC2 인스턴스의 초기 설정과 서비스 환경을 구성했습니다.

단순 리소스 생성이 아닌 네트워크 분리, 보안 구조, 운영 자동화까지 포함한 인프라 설계를 목표로 했습니다.

🏗 Architecture

  • VPC 내 Public / Private Subnet 분리
  • Internet Gateway + NAT Gateway 구성
  • Private Subnet에 EC2 배치
  • Multi-AZ 기반 고가용성 확보

🌐 Network

  • VPC : 10.0.0.0/16
  • Public Subnet : 10.0.1.0/24 (2a), 10.0.2.0/24 (2b)
  • Private Subnet : 10.0.11.0/24 (2a), 10.0.12.0/24 (2b)

🧭 Routing

  • Public Route → Internet Gateway
  • Private Route → NAT Gateway
  • Private Instance 외부 직접 접근 차단

💻 Compute

  • Instance A → Private Subnet (AZ-2a)
  • Instance B → Private Subnet (AZ-2b)
  • AZ 분산으로 장애 대응 가능

⚙️ Automation Flow

[Terraform] → VPC → Subnet → IGW / NAT Gateway → Route Table → EC2 ↓ [Ansible] → 서버 접속 → 패키지 설치 → 환경 설정 → 서비스 구성

💡 Key Points

  • Infrastructure as Code 기반 인프라 자동화
  • Public / Private 네트워크 분리
  • Multi-AZ 기반 고가용성
  • Terraform + Ansible 역할 분리

📈 Result

  • 인프라 구축 자동화 경험 확보
  • 클라우드 네트워크 설계 이해도 향상
  • 운영 환경을 고려한 구조 설계 경험

🔥 Summary

Terraform과 Ansible을 활용하여 고가용성 클라우드 인프라를 자동 구축하고 서버 구성까지 일관되게 관리한 프로젝트입니다.
