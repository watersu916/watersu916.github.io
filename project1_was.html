Manual 7-Node WAS Infrastructure 구축

VirtualBox Linux HAProxy MySQL NFS DNS

Overview

VirtualBox 기반 환경에서 7개의 서버를 직접 구축하며 웹 서비스 인프라의 전체 흐름을 이해하고자 한 프로젝트입니다. Load Balancer, Web, NAS, DB, SAN, DNS 구조를 분리하여 구성하고 각 컴포넌트 간의 네트워크 흐름과 역할을 명확히 설계했습니다.

Architecture

  • Load Balancer: HAProxy 기반 트래픽 분산
  • Web Server: Apache + PHP 기반 WordPress 서비스
  • NAS: NFS 기반 웹 콘텐츠 공유
  • DB Server: MySQL 데이터 관리
  • SAN: iSCSI 기반 스토리지 제공
  • DNS: 도메인 기반 서비스 접근
  • Client: 서비스 접근 테스트

Key Implementation

  • iSCSI 기반 SAN 구성 및 DB 스토리지 분리
  • NFS를 활용한 Web 서버 간 데이터 공유
  • HAProxy를 통한 Web 서버 이중화 및 로드밸런싱
  • DNS 서버 구축을 통한 도메인 기반 접근 환경 구성
  • MySQL 사용자 권한 및 네트워크 접근 제어 설정

Troubleshooting

  • NFS 마운트 실패 → 방화벽 및 SELinux 설정 문제 해결
  • DB 연결 오류 → MySQL 사용자 권한 및 host 설정 수정
  • 로드밸런싱 불균형 → HAProxy 설정 튜닝
  • iSCSI 연결 문제 → Initiator/Target 설정 검증

Impact

단일 서버 환경이 아닌 분산 아키텍처를 직접 구축하며 서비스 구조에 대한 이해도를 높였고, 이후 Kubernetes 및 클라우드 기반 인프라 설계로 확장할 수 있는 기반을 마련했습니다.
